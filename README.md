# @uncle7/starmap-2d

**把按标准结构组织的站点内容，变成一张可截图的星图。**
一级是一排环，二级是一段可以钻进去的**光隧**。

库不知道你的内容是什么。它只认 `Manifest` 这一个结构。

```bash
npm i @uncle7/starmap-2d
```

```ts
import { createJourney } from '@uncle7/starmap-2d'

const journey = createJourney(document.querySelector('#stage'), manifest, {
  onEnterCruise: (i) => console.log('进入第', i, '段光隧'),
})
```

宿主需要给容器一个**明确的高度**（`position:fixed; inset:0`，或 `width/height:100%`）。
库只填满宿主给的盒子；盒子高度为 0 时它会警告，而不是静默画错。

**零运行时依赖** —— 没有 three.js，没有 canvas 库。一级和二级都是 Canvas 2D。

---

## 两级视图

```
一级 · 环行场景     一排环，从左往右，间距拉开，环里没有照片
      │ 点击一枚环
      ▼
二级 · 光隧         一条不断往外淌的流：照片从鼠标位置一张张飞出来
```

| | `@uncle7/starmap`（三维版） | `@uncle7/starmap-2d`（本包） |
|---|---|---|
| 一级 | three.js 星图 | **Canvas 2D 环行场景** |
| 二级 | three.js 光隧 | **Canvas 2D 流动光隧** |
| 运行时依赖 | three | **无** |

两个包共用同一套内容标准（`Manifest`）、同一套档位状态机。
换渲染器不换内容。

## 一级 · 环行场景：先叠着，再拉开

```
      ◎        ◎        ◎        ◎        ◎
   AIGC 创新实践周   跨校毕业设计训练营   临平科技馆 …
```

**一级是索引，不是内容。** 每一站一枚环，**环里不放照片** —— 照片留给二级。

**默认进入时，所有环按原来的顺序叠在画幅正中间** —— 间距被压到 9px，
一枚一枚错开，每一枚露出前面那枚的一点边。

但**只有前四五层看得清**：再往后的按层递减，暗到看不见 —— 十三层全摞在一处
只会糊成一片。环展开的时候，那些暗掉的才一个个显出来。

指针一动，环就**一个一个拉开**：每一枚都有自己的时刻，前一枚还没走完，后一枚才开始动。
拉开之后就是上面那一排，从左往右，间距 320。

环上：**时间地点在环上，站名在同一段环线的下面**。
环上的字**点得动** —— 点圈、点时间地点、点站名，都直接进那一站。

右边的面板不是「当前这一环的介绍」，而是**整个内容的介绍**：
上面一句总述（`部分培训剪辑`），下面列出**所有**站点 —— 时间 + 地点，当前站亮着。
**列表跟着环的展开往下走**：环开到第几站，列表就滚到第几站；
列表装不下时可以自己滚（自己滚过就不再自动跟随，滚回来才重新跟上）。
点列表里的一项 —— 点时间、点地点、点整行都算 —— 直接进那一站的光隧。

- **每一枚环都带字**，压在后面的暗到看不清；当前站那枚最亮、压在最上层。
- **光心跟着指针走**（带滞后，甩起来有惯性）。场景的底是一团光：
  同心光环从光心一圈圈涨开、扩散掉。于是光在屏幕上随意游动。
- **环滚进画幅时会涨进来**，不是突然出现在那儿。
- 越靠当前站的环越亮、越大；远处更暗，但暗到仍数得出有几站。
- **滚到文字面板下面的环会淡出** —— 文字不能被环压住。

```
    晃动指针               把环一个一个拉开（站点列表也跟着一条条显出来）
    滚轮 / 指针横向拖     翻站
    点任意一枚环           进入那一站的光隧
    点列表里的一项         进入那一站的光隧
```

## 二级 · 光隧：一条不断往外淌的流

鼠标所在的地方是源头。照片从那儿一张张冒出来，越飞越远；
背景是一圈圈涨开的光环 —— **光环和照片走的是同一条流**。

```
        ◎ 光圈（带站名）
      ◎    ◎      ◎     ← 照片从鼠标位置散开
   ◎             ◎
```

**同屏数量没有上限** —— 它由「存活时长 ÷ 发射间隔」自然决定。
飞得慢、活得久，屏上就堆得多。

### 发牌靠指针

- 指针每划过 **80 像素**发一张；
- 指针不动，也有保底的定时器（0.36 秒一张）在发。

所以画面永远不会停 ——「一直有照片飞出来」是默认状态，不是「鼠标动了才有」。

同屏数量**没有上限**，但也不该密得看不清 ——
默认节奏下场上稳定在 **12～14 张**，跟「流动感实验台」的光隧模式一个量级。
真要更密，把发牌间隔调小就行。

### 节奏：慢

全部按**秒**控制，不按「流相位」：

| | |
|---|---|
| 胀大 | 0.9 秒 |
| 照片离场 | 5 秒 |
| 章名环离场 | 5 秒（跟照片一样慢，环要化很久才不见） |
| 站名化开 | 最多 1.2 秒 |
| **站与站之间** | **空一拍：1 秒** |

慢到能看清一张照片，再看它化掉。指针越快，流得越快 ——
**快就是掠过**。

### 站与站之间空一拍

一站的照片飞完了，**先空一秒**，再出下一站的环，然后才是下一站的图。

这一拍是给眼睛的：上一站的图还在往外飘，画面安静下来，
新站的环单独待一会儿，名字才读得清。

按档位缩：慢慢读的时候留足 1 秒；快速跳过时 0.3 秒 —— 不然跳过也不快。

### 章名环

每一站先飞出一枚环：**时间地点在环上，站名在同一段环线的下面**。

```
        ╭───────────────────────────╮
        │                           │
        │      双圈 + 刻度的表圈      │
        │  2024.04.08 · 南京艺术学院   │   ← 内弧：时间 地点
        ╰───────────────────────────╯
         AIGC 创新实践周              ← 环外下弧：站名
```

**环和字都加粗** —— 背景还有一圈圈装饰环，
不粗一点就分不清哪个是站名、哪个是装饰。

**同时只有一枚环带字。** 快速操作时一口气跳过十几站，
旧环就只剩圈 —— 十几个站名同时挂在屏幕上会叠成一堆字。

站名化开的时间**跟这一站待了多久走**：
慢慢读的时候它慢慢模糊；快速跳过的时候它赶紧走。

三件让弧形文字站得住的事：

1. **上弧和下弧的转角不同**（`ca + π/2` / `ca - π/2`）。用错一条下弧的字会倒过来。
2. **字描一圈深色边。** 环上的字会压到浅色照片上（海报、课堂照），
   浅蓝字在浅色海报上几乎读不出来。描边是**字缘**，不是底板。
3. **弧长有上限。** 字太长就缩字号 —— 不缩的话一圈字首尾相接叠成一坨。

### 档位是「跳过」

**慢 = 全放，快 = 只放高亮。**

| 指针 | 档位 | 放行 |
|---|---|---|
| 慢 | 0 | 高亮 + 概览 + 细节 |
| 中 | 1 | 高亮 + 概览 |
| 快 | 2 | 只放高亮 |

快速操作时把细节跳过，慢下来才一张张看清。
（`TierTracker` 的档位数值不变，消费的一侧用 `放行层数 = 2 - 档位`。）

### 面板只有两行

```
2024.04.08 · 南京艺术学院
AIGC 创新实践周
```

第一行是时间地点，下面是站名 —— 没有计数，没有简介、角色、受众。

```
    滚轮 / ← →             跳一站
    点照片                 拿到眼前来看
    Esc                    退回一级场景
```

### 确定性

没有 `Math.random()`：素材按 manifest 的顺序取，星尘用固定种子的 mulberry32。
同一站永远以同样的顺序出场 —— 这个库的用途之一是**被截图**，
每次刷新都换一套的库没法当效果资产用。

`journey.freeze()` / `journey.thaw()` 可以把画面钉住再截：截图往返有几百毫秒，
稍纵即逝的帧抓不住，只能先停住。

## 内容契约

库只认 `Manifest`：

```ts
interface Manifest {
  title?: string
  stations: Station[]
}

interface Station {
  id: string              // kebab-case，唯一
  title: string
  date?: string           // YYYY-MM / YYYY-MM-DD，排序唯一依据
  end?: string
  place?: string
  short?: string          // 标注用的短地名，缺省用 place
  role?: string
  audience?: string
  lead?: string
  summary?: string
  draft?: boolean         // 未校订的占位文案
  images: ImageRef[]      // { src, tier: 0|1|2, caption? }
}
```

**能校验的绝不默认值。** 字段缺失有明确的降级路径，字段写错必须报错，
而不是悄悄按缺省渲染出一个错的页面 —— `validateManifest()` 会抛 `ManifestError`（带路径）。

`images[].tier` 就是 LOD：`0` 高亮 / `1` 概览 / `2` 细节。
目录分类同时就是 LOD 数据。

把标准目录读成 manifest 用附带的工具：

```ts
import { readStations } from '@uncle7/starmap-2d/content'

const manifest = await readStations('./stations', { base: '/stations' })
```

## API

```ts
const journey = createJourney(container, manifestInput, options)
```

| 选项 | 默认 | 说明 |
|---|---|---|
| `speedBase` | 260 | 指针速度基准（px/s）。档位判定用**相对倍率**，换设备只改这一个数 |
| `forceTier` | `null` | 强制档位（0/1/2），给自动化与截图用 |
| `hint` | — | 开场提示语。不给就不显示 —— 库里不替宿主说话 |
| `debug` | `false` | 画面上显示读数 |
| `onEnterCruise` | — | 进入第 i 站光隧 |
| `onBackToScene` | — | 回到环行场景 |
| `onHover` | — | 站点被悬停 |

| 方法 | 说明 |
|---|---|
| `journey.goto(i)` | 跳到第 i 站的光隧 |
| `journey.toScene(index?)` | 回到一级场景；带 index 时顺带落到那一站 |
| `journey.next()` / `prev()` | 光隧里前进 / 后退一站 |
| `journey.freeze()` / `thaw()` | 定格 / 恢复（截图用） |
| `journey.on('view' \| 'hover', cb)` | 订阅视图与悬停 |
| `journey.debug()` | 取景与投影的真实数值。**排布是纯函数，出问题要看数，不要靠感觉** |
| `journey.destroy()` | 拆掉 |

## 开发

```bash
pnpm install
pnpm gen:manifest   # 把 ../stations 读成 examples/demo/public/manifest.json
pnpm dev            # 起 demo
pnpm typecheck
pnpm check:tier     # 档位状态机的 11 条断言
pnpm build
```

`examples/demo/public/stations` 是指向 `../stations` 的目录联接（Windows 本机用）。
正式接入时素材前缀由宿主的静态资源根决定，库本身不关心。

### 目录

```
src/
  types.ts           内容契约与校验
  window.ts          速度平滑 + 档位状态机（与三维版同一份）
  content/reader.ts  把标准目录读成 manifest（Node 侧）
  field.ts           底子：光心 + 同心光环 + 星尘（一二级共用）
  ring.ts            环徽章：本体 + 弧形站名 + 弧形时间地点（一二级共用）
  scene.ts           一级 · 环行场景
  cruise.ts          二级 · 光隧（一条不断往外淌的流）
  index.ts           公共 API + CSS
```

**一二级共用 `field.ts` 和 `ring.ts`** —— 同一个光心、同一种扩散节奏、
同一套字的画法。换视图就换质感，会让人以为换了个产品。

`field.ts` 里的光环半径由 `flow` 决定，而 `flow` 就是二级光隧里
照片飞出去的那条流 —— 光环和照片永远同步。
